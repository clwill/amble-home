Your amaran account

Saved sign-in


Kept in plain storage on the box, next to its Wi-Fi password, until you press Forget.

Your amaran password goes to this box over your home network, is used for one sign-in, and is not stored, unless you tick Remember. The box hands back a one-time token and this page reads your mesh.

The app's database

Open the amaran desktop app's amaran.db. It is read in this browser; only the fixtures you tick and the mesh keys they need are sent to this box, on your network.

Where is amaran.db?

A web page cannot search your disk, but the file dialog can jump straight to the folder.

macOS: the file lives inside the amaran Desktop app's sandbox, which the file dialog hides. In the dialog press ⌘⇧G first, then paste this folder with ⌘V and press Return. Open the folder whose name ends in _secure_id (such as 80112112_secure_id) and pick amaran.db:
~/Library/Containers/com.sidus.amaran-desktop/Data/Library/Application Support/amaran Desktop/

Windows: usually under %APPDATA%\amaran Desktop\; paste that into the dialog's address bar. If it is not there, search your user folder for amaran.db.

Quit the amaran app first if the file will not open, and never move or delete it: the box only reads a copy.
