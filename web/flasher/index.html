amble-home · Flash

Amaran BLE for ESPHome. This puts the amble-home firmware on an ESP32-S3 or ESP32-C6 board from your browser; the page picks the right image for the chip it finds. Nothing to download, no toolchain, under ten minutes from a bare board to lights in Home Assistant.

Your browser cannot flash over USB. Use Chrome or Edge on a computer. This page must be opened over HTTPS to flash.

Firmware version: …

Before you start

  • A computer running Chrome or Edge. Firefox, Safari and phones cannot flash (no Web Serial).
  • An ESP32-S3 or ESP32-C6 board from the README's boards table (8 MB of flash or more; PSRAM not needed). Older ESP32 chips are not supported.
  • A USB data cable in the port that is not labelled COM or UART. A board with one port uses that one.

Steps

  1. Plug the board into the computer.
  2. Put it into install mode: hold BOOT, tap RESET, release BOOT. (The M5Stack Atom has no BOOT button: hold its side button for about two seconds until the LED turns green.) This only opens the board for installing; it does not clear anything.
  3. Press Connect and pick USB JTAG/serial debug unit in the port list.
  4. Choose Install and let it run (one to three minutes). On a fresh board, tick erase when offered.
  5. When it says Installation complete, tap RESET once (or unplug the board and plug it back in). A board put into install mode by hand stays there after the flash until it is reset, so the page would otherwise offer to install again.
  6. Press Connect again, pick the same port, and choose Connect to Wi-Fi. If you skip this, the box starts its own network called amble-home- plus six letters; join it and a setup page appears.
  7. Once the box is on your Wi-Fi, choose Visit Device to set up your amble-home for your fixtures: it opens the box's Home page; follow Edit to import them from the amaran app's database or your amaran account. From any other browser the box is http://amble-home.local/ (its full name is amble-home- plus six letters). The README has the walk-through.

Updating or recovering a box

Flash the new version from this page the same way. If the page offers to erase the device, leave that unticked: your Wi-Fi, fixtures and PIN stay. Tick it only for a clean start, after which you set up Wi-Fi and import your fixtures again. One exception: a box flashed before 2026-10-30 carries the old 16 MB flash layout, and the first install of the current image lays the flash out afresh, so that box asks for its Wi-Fi and fixtures again once, erase ticked or not. ESPHome's command line can also send the .ota.bin for your chip over the network; a hosted update feed for Home Assistant comes with the public release.

amble-home is open source (MIT). The box never phones home; the only thing this page downloads is the firmware image next to it.
